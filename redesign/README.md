# Saanjh Foundation redesign

## Run locally

From this directory:

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

The deployable static output is `dist/`. The original live website is unchanged.

See CONCEPT.md for the existing-site analysis, design direction, page structure, REA evidence and publication status.

Content: `src/App.tsx`; team data: `src/team.json`; design: `src/style.css`; official animation component: `src/registry/magicui/text-animate.tsx`.

Contacts and team portraits were retained from the existing public Saanjh website. No form sends messages automatically and no donations are collected.
